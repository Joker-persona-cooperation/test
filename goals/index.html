TaskPilot 前端预览

面向任务型文档的 AI 拆解助手。以下页面为前端开发的最终成品目标预览，使用 HTML 构建，技术栈对标 Vue3 + Element-Plus + vue-router + axios + pinia。点击任意卡片查看对应页面。

Vue 3 Element Plus Vue Router Pinia Axios TypeScript Sass Day.js

登录页

邮箱密码登录，JWT 鉴权，登录后跳转工作台

注册页

邮箱注册，设置昵称与密码，注册即签发 Token
主链路页面

工作台首页

欢迎信息、数据统计、最近记录、今日提醒

解析详情页

左侧原文预览，右侧结构化结果编辑，保存为项目

项目列表

项目卡片展示，状态筛选，查看项目详情

项目详情 / 任务看板

任务看板多列泳道，新增编辑删除，状态切换
